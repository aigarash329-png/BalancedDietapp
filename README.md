A lightweight, interactive web application designed to help users select nourishing, balanced daily menus based on their current physical and mental well-being. Built with holistic health principles in mind, the app features custom character illustrations to guide users through an engaging meal-selection experience.  FeaturesInteractive Menu Selection: Guides users through three quick questions assessing their physical condition, preferred ingredients, and cooking style/time.  Personalized Recommendations: Generates tailored meal plans (featuring main dishes, side dishes, and soups) categorized by vitality, relaxation, or recovery needs.  Character Guidance: Integrates avatar expressions (MiniAyuHello.png, MiniAyuThink.png, MiniAyuHappy.png, etc.) to create a warm and supportive user experience.  Zero Dependencies: Built as a single, self-contained HTML file with embedded CSS and JavaScript, requiring no external frameworks or build tools.  Setup & GitHub Pages DeploymentTo host this app for free using GitHub Pages, follow these simple steps:Prepare your repository:Create a new repository on GitHub (e.g., ayu-balanced-meal-app).  Upload files:Save the code as index.html and upload it to the root directory of your repository.  Optional: Upload your character image files (MiniAyuHello.png, MiniAyuThink.png, MiniAyuHappy.png, MiniAyuSuggestion.png, MiniAyuReleved.png) into the same root folder so the app can load them. (Built-in SVG fallbacks will display automatically if image files are missing).  Configure GitHub Pages:Navigate to your repository's Settings tab.  Click on Pages in the left-hand sidebar.  Under Build and deployment, select your main (or master) branch as the source and / (root) as the folder, then click Save.  Access your live app:After a few moments, GitHub will provide a live URL where your Balanced Meal Planner app is successfully published and ready to share.  License© Ayu Natural Therapy.
